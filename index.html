Нужен е безплатен ключ за YouTube

Страницата търси клиповете в YouTube и ги пуска оттам, без да ги тегли. За търсенето YouTube изисква личен ключ – взима се за 2 минути и е безплатен.

  1. Отвори Google Cloud Console и влез с Google профил.
  2. Създай проект и натисни „Enable“ на YouTube Data API v3.
  3. От „Credentials“ избери „Create credentials → API key“ и го копирай.
